#            A locus in parentheses is used as written: SlWOX4 (Solyc04g078650)
# Column 2: genus and species of that characterized gene.
#
# Locus IDs match with or without an isoform suffix (Solyc04g078650 = Solyc04g078650.4.1).
# A symbol matches the annotation symbol, or a description with the same family and
# number. ITAG has no WOX4 token; the note is "wuschel related homobox 4".

# The resolution of every name is written to gene_id_crosswalk.tsv.
# Optional: --candidate_cds is a FASTA of the characterized CDS for each gene.
# A tab follows the gene name. Spaces then separate species, locus, and annotation:
#   >WOX13	Arabidopsis thaliana AT4G35550.1 TAIR10
# That CDS is translated and compared with the annotation protein, and the
# nucleotides are compared with the annotation CDS. See candidate_cds.example.fna.
